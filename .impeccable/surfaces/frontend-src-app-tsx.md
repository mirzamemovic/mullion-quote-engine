# Owner app (phone first, also PC)

Scope: the whole owner app and its admin screens. Mode: Operate.
Task: measure an opening while measuring, get a priced quote, show the client the price before leaving. Constraints: sunlight, one hand, Viber-level user, little text, every number explainable.

## Direction contract

THESIS: Every size is written where it was measured, and every number opens to show its sum. Refuses the category default of a long labelled form of fields on white cards.

OWN-WORLD: Skimmed-plaster ground (cool light grey), carpenter's-graphite ink and shell bar, chalk-line blue for the active field, selection and dimension strings, red marking crayon only for readings or values he must re-check, a quiet green only for accepted/paid. System UI face, heavy weights, tabular numerals; three numeral sizes only. Dimension strings (line with end ticks, number above) mark every size.

STORY: He sees where he is, fills the next slot, sees the window size and, on the summary, the price; any number unfolds into its formula or price layers.

FIRST VIEWPORT: Graphite top bar (back, position and quote). Progress ticks. One compact colour row (white / foil outside / foil both sides), because the installation gap and so the window size depend on the colour. Opening drawn from inside: three width slots top/middle/bottom, three height slots left/right/middle at the places he measures; active slot chalk-blue; smallest reading circled. Bottom sheet: window size in the largest numerals, "Kako je izračunato?", primary chalk-blue button.

FORM: Pencil on the site wall, position 6 of 7, seed:2d2c25e3e4cb3178. Raises: fixed tabular columns (split-flap); drawings are the buttons (metro tiles); bar rows like timed sides, offcut last (j-card); three-size numeral ramp (star atlas); edited item opens, others fold (streaming wall); only 45° and 90° in drawings (transit map).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
